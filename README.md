# NexusHub Omarchy Theme

A dark, glassy Omarchy theme inspired by Japanese dusk landscapes, warm ember accents, and the NexusHub visual language.

## Status

Early alpha. The core palette is ready for testing. Wallpaper and polished previews are coming next.

## Install

```bash
omarchy theme install https://github.com/thabopal/omarchy-nexushub-theme.git
```

Then select **Nexushub** from Omarchy's theme picker.

## Revert

Nothing in this theme replaces Omarchy's stock themes. Switch back at any time from the normal Omarchy theme picker.

## Palette direction

- near-black graphite surfaces
- warm ember / terracotta accent
- soft parchment foreground
- muted plum and slate secondary tones
- restrained cyan/green status colours

## Companion dashboard

The functional QML widgets and dock live separately in [`thabopal/omarchy-nexushub-dashboard`](https://github.com/thabopal/omarchy-nexushub-dashboard).
